# QuadSplit AI

生成 AI（Gemini など）が出力する「4面図画像（田の字型）」を、自動解析して個別の画像に分割・保存する Web ツールです。

🔗 **[ツールを開く](https://image-splitter-1014371658424.asia-east1.run.app/)**

---

## 機能

**インテリジェント自動境界解析**  
アップロードした画像の色情報のばらつきをスキャンし、最適な分割位置（余白ライン・キャラクター境界）を縦・横それぞれ自動検出して分割線を配置します。

**スムーズな分割線カスタマイズ**  
分割線はドラッグでピクセル単位に微調整できます。ドラッグ中は描画処理を最適化しているため重い画像でも滑らかに操作でき、マウスを離した瞬間にプレビューが再構築されます。

**自由なマルチスプリット**  
4分割（田の字）に限らず、分割線を追加・削除することで3枚・6枚・9枚など任意の枚数に分割できます。

**一括ダウンロード**  
分割した画像を1枚ずつ保存することも、「全ての画像を保存」ボタンで一括保存することもできます。

## 使い方

1. [ツールを開く](https://image-splitter-1014371658424.asia-east1.run.app/)
2. 分割したい画像をドラッグ＆ドロップ（または「Browse Files」から選択）
3. 自動で分割線が配置されるので、必要に応じてドラッグで調整
4. 右側のプレビューで結果を確認し、「全ての画像を保存」でダウンロード

### 分割線の操作

| 操作 | 内容 |
|---|---|
| 分割線をドラッグ | 位置をピクセル単位で調整 |
| `+ 垂直線` ボタン | 縦の分割線を追加 |
| `+ 水平線` ボタン | 横の分割線を追加 |
| 分割線の `×` ボタン | その分割線を削除 |

## よくある質問

**ダウンロードが途中で止まる**  
ブラウザのセキュリティ設定で複数ファイルの同時ダウンロードがブロックされている場合があります。アドレスバー付近に表示されるダイアログで「このサイトからの複数ダウンロードを常に許可する」を設定してください。

**最初からやり直したい**  
プレビュー上部の「クリア」ボタンで画像をリセットできます。
